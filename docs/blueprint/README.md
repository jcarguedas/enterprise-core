# Enterprise Core Blueprint

El Blueprint contiene la visión técnica y estratégica del proyecto Enterprise Core.

Su propósito es documentar las decisiones fundamentales de arquitectura, principios de ingeniería y objetivos del producto.

## Contenido

- Vision
- Mission
- Architecture
- Principles
- Engineering Standards
- Definition of Done
- Roadmap

Las decisiones arquitectónicas específicas se encuentran en la carpeta ADR.
