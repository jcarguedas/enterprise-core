# Architecture

Enterprise Core será construido utilizando una arquitectura modular.

Cada servicio tendrá una responsabilidad claramente definida y podrá evolucionar de manera independiente.

## Servicios previstos

- Auth Service
- Company Service
- User Service
- Inventory Service
- Catalog Service
- Payment Service
- Reporting Service

La inteligencia artificial será una capacidad transversal presente en todos los servicios, proporcionando recomendaciones y automatizaciones contextualizadas.

La comunicación entre módulos se realizará mediante APIs REST.
