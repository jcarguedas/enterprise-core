# Engineering Standards

## Convención de commits

feat(auth): implement JWT authentication

fix(users): validate duplicated email

docs(readme): update installation guide

refactor(api): simplify middleware

test(auth): add login feature tests

---

## Branches

main

develop

feature/<feature-name>

bugfix/<bug-name>

hotfix/<hotfix-name>

---

## Filosofía

- Código limpio.
- Commits pequeños.
- Responsabilidad única.
- Documentación viva.
- Automatización cuando aporte valor.
