# Definition of Done

Una funcionalidad se considera terminada únicamente cuando:

- Compila correctamente.
- Cumple los estándares del proyecto.
- Tiene documentación actualizada.
- Existe al menos una prueba funcional.
- Fue registrada mediante un commit siguiendo la convención.
- Si implicó una decisión arquitectónica, existe un ADR correspondiente.
- Está lista para revisión.
