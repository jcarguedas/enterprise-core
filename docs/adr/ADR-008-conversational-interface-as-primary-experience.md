# ADR-008: Interfaz conversacional como experiencia principal

- Estado: Aceptado
- Fecha: 2026-08-05
- Decisores: Jean Carlos Arguedas
- Proyecto: Enterprise Core

## Contexto

Las aplicaciones empresariales tradicionales obligan al usuario a navegar entre múltiples módulos, menús, reportes y formularios para obtener información o ejecutar acciones.

Enterprise Core busca ofrecer una experiencia más intuitiva, accesible y asistida por inteligencia artificial.

## Decisión

La experiencia principal del usuario estará centrada en un asistente empresarial conversacional.

La navegación tradicional continuará disponible como mecanismo complementario y de respaldo.

## Justificación

- Reduce la cantidad de pasos necesarios para realizar tareas.
- Facilita el acceso a información sin exigir conocimiento profundo de la estructura del sistema.
- Permite ofrecer recomendaciones contextuales.
- Acerca las funcionalidades al usuario en lugar de obligarlo a buscarlas.
- Refuerza la identidad de Enterprise Core como plataforma empresarial inteligente.

## Principios de interacción

- La experiencia deberá ser minimalista.
- La IA no deberá ser invasiva.
- Las recomendaciones deberán explicar su fundamento.
- Las acciones sensibles requerirán confirmación humana.
- El usuario conservará siempre el control final.
- La navegación tradicional seguirá disponible.

## Consecuencias positivas

- Menor curva de aprendizaje.
- Mayor velocidad para consultar información.
- Experiencia diferenciada frente a sistemas empresariales tradicionales.
- Mejor integración de la inteligencia artificial en los procesos operativos.

## Consecuencias negativas o riesgos

- Mayor complejidad en seguridad, permisos y trazabilidad.
- Posibilidad de interpretar incorrectamente una solicitud.
- Necesidad de diseñar confirmaciones claras para acciones críticas.
- Dependencia de información contextual de calidad.

## Alternativas consideradas

- Menús y dashboards como experiencia principal.
- Asistente de IA como módulo separado.
- Interfaz exclusivamente conversacional.
