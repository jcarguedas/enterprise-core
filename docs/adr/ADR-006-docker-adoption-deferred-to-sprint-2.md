# ADR-006: Adopción de Docker a partir del Sprint 2

- Estado: Aceptado
- Fecha: 2026-08-05
- Decisores: Jean Carlos Arguedas
- Proyecto: Enterprise Core

---

## Contexto

El proyecto inicia con un único servicio y un entorno local completamente funcional.

---

## Decisión

Docker será incorporado durante el Sprint 2.

---

## Justificación

- Evitar complejidad innecesaria durante el inicio.
- Priorizar el aprendizaje de Laravel, Git y PostgreSQL.
- Introducir Docker cuando existan múltiples servicios.

---

## Consecuencias positivas

- Menor carga cognitiva.
- Mayor enfoque en arquitectura y desarrollo.

---

## Consecuencias negativas

- El entorno inicial dependerá del sistema operativo local.

---

## Alternativas consideradas

- Docker desde el primer día.
